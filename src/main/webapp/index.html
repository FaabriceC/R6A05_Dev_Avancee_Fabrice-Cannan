MasterAnnonce API

Cette application est un backend API REST (JSON only) exposé sous /api. Aucun JSP n'est utilisé.

Endpoints de base

  • GET /api/helloWorld
  • GET /api/params?name=Fabrice (QueryParam)
  • GET /api/params/Fabrice (PathParam)

Authentification stateless

  1. POST /api/login avec JSON {"username":"admin","password":"admin"} → renvoie un token
  2. Appeler les endpoints protégés avec le header Authorization: Bearer <token>

Tester rapidement

Ouvre la console du navigateur et exécute :

// 1) Login
fetch("./api/login", {
  method: "POST",
  headers: {"Content-Type":"application/json"},
  body: JSON.stringify({username:"admin", password:"admin"})
}).then(r => r.json()).then(({token}) => {
  // 2) Appel protégé
  return fetch("./api/annonces?page=1&size=5", {
    headers: {"Authorization": "Bearer " + token}
  });
}).then(r => r.text()).then(console.log);
